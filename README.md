## 🔄 كيف تحدّث النظام لاحقاً (إضافة ميزة أو تعديل)
1. اطلب من Claude التعديل المطلوب على ملف `index.html`
2. حمّل النسخة الجديدة من المحادثة
3. روح لمستودع GitHub ← افتح ملف `index.html` الموجود ← اضغط أيقونة القلم (Edit)
4. احذف كل المحتوى القديم والصق محتوى الملف الجديد كاملاً
5. اضغط **Commit changes**
6. انتظر دقيقة إلى دقيقتين ليتحدّث الموقع تلقائياً
